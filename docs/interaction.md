# 操作と状態の見せ方

G2 の入力は、つるのタッチパッド（または指輪型の R1）からの上下スワイプ・タップ・ダブルタップ・長押しです。ポインティングはできないので、選択を上下に 1 つずつ動かしてタップで決めます。

この文書では、部品集が実装している処理と、アプリ側で守る規約を分けて書きます。

## 部品集が実装している処理

### 入力の正規化 `createInputPolicy()`

`events` の `classify()` で分類した操作の種類を受け取り、次の規則を通してから返します。捨てる場合は `null` を返します。

| 規則 | 値 |
|---|---|
| 上下のスワイプを間引く | 前に通したスワイプから 350ms 未満は捨てる |
| 誤タップを捨てる | タップ以外の操作の直後 200ms 未満のタップを捨てる。タップの後のタップは捨てない |
| 上下反転 | 設定がオンなら上と下を入れ替える |

誤タップの起点になる「タップ以外の操作」は、上・下・ダブルタップ・長押し・長押しの解除・OS メニューの項目選択・OS メニューの開閉（`fg_enter` / `fg_exit`）です。間引きで捨てたスワイプも起点として記録します。

`acceptWithReason()` は捨てた理由（`'tap-guard'` / `'swipe-gate'`）も返します。間引きの判定は内部の時刻 0 から始まるため、`now` に 0 付近の値を渡すと最初の 1 回が通りません。実時刻（`Date.now()`）を渡す前提です。

### 長押しの連続送り `createHoldRepeat()`

長押ししている間、直前の上下を繰り返します。キーボードのキーリピートと同じ考え方で、新しいジェスチャーを増やさずに連続送りができます。

- 最初の 1 歩は押してから 400ms 後（押した瞬間には送らない）
- 以後 400ms ごと
- 次のどれかで止まる: `stop()`、60 回、30 秒、`step` が `false` を返す（端に着いた）、`key` の値が開始時と変わった（画面が切り替わった）

離したという合図が届かなくても、回数と時間の上限で止まります。どちらへ送るか（直前の上下、無ければ次）と、本文の最後のページで次へ送らない判断は、アプリが `step` の中で行います。

### 一時通知 `createToast()`

通知の文字列を保持し、1.5 秒後に消して `onChange` を呼びます。保持している文字列を header に表示するのはアプリ側です。表示中に次の通知が来たら、そこから 1.5 秒数え直します。

### 初回ヒント `createFirstRunHint()`

画面ごとの表示回数を `<appKey>.hintCount` に JSON で保存し、最初の 3 回だけ表示します。最初の操作でヒントを消したときに `seen()` を呼んで 1 回数えます。`resetAll()` はスマホ側の「もう一度出す」設定から呼ぶためのものです。起動時に `load()` を 1 回呼んでおく必要があります。

### 再試行 `createRetry()`

取得に失敗したら 30 秒後に自動で再試行し、待っている間のタップで即座に再試行します。成功するまで 30 秒ごとに繰り返し、`stop()` で画面を離れるときに待機を捨てます。

### OS メニュー `buildMenu()`

OS のコンテキストメニューの項目を、共通項目を先頭、画面固有の項目を後ろにして並べます。項目は 10 個まで、ID は 1 以上で重複なし、項目名は UTF-8 で 32 byte までです。10 個の上限にシステム側の項目（画面オフ・明るさ・閉じる）が含まれるかは確かめられていません。

## アプリ側で守る規約

次の規約は画面遷移を持つアプリ側の実装で、この部品集には含まれていません。部品はこの規約に合わせて作られています。

| 操作 | 一覧 | 本文 | 確認 |
|---|---|---|---|
| タップ | 開く | 表示を消す | 決める |
| ダブルタップ | 1 段外へ戻る | 一覧へ戻る（開いた項目を選んだまま） | やめる |
| 上 | 前の項目（先頭で止まる） | 前のページ（先頭ページでは何もしない） | 前の選択肢 |
| 下 | 次の項目（末尾で止まる） | 次のページ。最後のページなら次の項目の先頭 | 次の選択肢 |
| 長押し | 直前の上下を繰り返す | 直前の上下を繰り返す | — |

- 一覧のカーソルは端で止まり、反対側へ回り込まない
- 本文の最後のページから次の項目へ進むのは、手で送ったときだけ。長押しの連続送りでは最後のページで止める
- 最後のページを描き終える前の「次へ」は無視する。表示が追いつく前に次の項目へ進むのを防ぐため
- 確認画面のタップは、確認画面を描き終えてから 600ms（`CONFIRM_TAP_GUARD_MS`）経つまで捨てる
- 表示を消した後は、ダブルタップで消す前の画面に戻す。戻してから 1.5 秒（`UNHIDE_GRACE_MS`）は再び消さない
- 確認画面を出すのは取り消せない操作（中断・削除・外部への送信）だけ

## 状態の見せ方

状態は専用の欄を増やさず、上段の 1 行か本文枠の中で見せます。標準の文言は `WORDS`（日本語・英語）から取ります。

| 状態 | 見せ方 | 文言（ja） |
|---|---|---|
| 読み込み中 | 本文枠の中央に 1 行（`card()` + `centeredLabel()`） | 読み込み中… |
| 空 | header だけに出す。本文枠もヒントも出さない（例 `ブックマーク　該当なし`） | 該当なし |
| エラー | header に 1 行。タップで再試行し、30 秒ごとにも自動で再試行する | 取得に失敗　タップで再試行 |
| 未接続 | 上段の右、位置・時計の左 | 未接続 |
| 一時通知 | header の文字を 1.5 秒差し替える | — |
| 端に着いた | 位置を表示していない画面でだけ一時通知を出す | これ以上ありません |
| 初めての画面 | 本文枠の下端に 1 行。画面ごとに最初の 3 回 | — |

操作ヒントは「操作名 + で + 結果」の形（`タップで再試行`）で書きます。

## 描画の作り直しと更新

SDK には、container の集合を作り直す `rebuildPageContainer` と、文字だけを差し替える `textContainerUpgrade` があります。どちらを使うかはアプリが決めます。部品は判定の材料として `topBar()` の `shapeKey` を返します。

- `'two'` の `shapeKey` は、right の幅を変える要素（未接続、進捗バーの有無、総数の桁数）と言語・文字色の組
- `'one'` の `shapeKey` は言語と文字色だけ。題名・位置・時計・未接続が変わっても header の文字の差し替えで済む

一覧のカーソル移動では枠の色と高さが変わるため、作り直しになります。
